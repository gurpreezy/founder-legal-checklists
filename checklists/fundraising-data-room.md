# Fundraising Data Room Checklist

A clean data room signals a clean company. Investors read disorganization as risk. Assemble this *before* you start pitching, so diligence never stalls your momentum.

> Educational checklist, not legal advice. Deeper reading at [blegal.ai — SAFE & Venture Capital](https://blegal.ai/knowledge/safe-venture-capital).

## 1. Corporate
- [ ] Certificate of incorporation + amendments
- [ ] Bylaws
- [ ] Board and stockholder consents/minutes
- [ ] Good-standing certificate

## 2. Capitalization
- [ ] Fully-diluted cap table reconciled to signed docs
- [ ] All SAFEs, notes, warrants
- [ ] Option plan, grant approvals, 409A valuations
- [ ] Founder stock purchase agreements + 83(b) filings

## 3. Intellectual property
- [ ] IP assignments from all founders, employees, contractors
- [ ] Trademarks, domains, patents (if any)
- [ ] Open-source inventory

## 4. Commercial
- [ ] Top customer and vendor contracts
- [ ] Any contract with change-of-control or assignment clauses
- [ ] Key partnerships or licenses

## 5. People
- [ ] Employee and contractor agreements
- [ ] Confirmation of at-will status
- [ ] Any equity promises not yet documented (flag and resolve)

## 6. Financial & legal
- [ ] Financial statements / model
- [ ] Debt, loans, liens
- [ ] Any pending or threatened litigation

## Structure tip
Mirror these six folders exactly. When counsel's request list maps cleanly onto your folders, diligence takes days instead of weeks — and speed is leverage in a competitive round.
